# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository
(private vulnerability reporting). Do not open public issues for security problems.

Include what you found, how to reproduce it, and the impact you expect. Test only against your own local stack
(`npx supabase start`) or accounts you own; do not run automated scans against a deployed FrogType instance.

The current security posture, test evidence and known limitations are documented in [docs/security](docs/security/).
